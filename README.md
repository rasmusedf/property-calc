# Property Calculator

A Mob Wars: La Cosa Nostra property ROI calculator. Enter your holdings and it ranks the next buy.

The app is a static site. Nothing is stored on a server. Saves stay in your browser. Use Settings to export or import a JSON backup.

```bash
npm install
npm run dev
```

Production is GitHub Pages. Each push to `main` builds the static files and publishes them. There are no serverless functions, APIs, or paid hosts.
